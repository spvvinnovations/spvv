SPVV INNOVATIONS WEBSITE
========================

Included:
- index.html
- css/style.css
- js/script.js
- images/spvv-logo.png
- images/spvv-services-banner.png

Run locally:
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Install the "Live Server" extension if needed.
4. Right-click index.html -> Open with Live Server.

Brand colors:
- Navy Blue: #071744
- Cyan: #00CFE8
- Light Cyan: #68EFFF

Important before publishing:
- The contact form is a front-end demo that opens an email draft. Add your official business email or connect a backend/form service to receive enquiries.
- The site says "6 clients served" based on the information provided by the user.
- Verify the official domain before publishing. The banner image currently contains "spvvinnovations.com"; only use it if you own/control that domain.
- The provided logo and services banner images are included in images/.

Latest update: the Our Work section now uses separate visual service modules/cards instead of displaying the full poster as one large image.
